# Maintainers

Patent Capital OS uses a primary-maintainer model while the project is early.

## Primary/Core Maintainer

| Maintainer | GitHub | Role | Scope |
| --- | --- | --- | --- |
| ares20041129-jpg | [@ares20041129-jpg](https://github.com/ares20041129-jpg) | Primary/core maintainer | Roadmap, releases, security boundary, workflow contracts, and final merge decisions |

## Maintainer Responsibilities

- keep the local no-official-submission boundary truthful
- review changes to legal/compliance gates, hash binding, path safety, and filing-state transitions
- triage issues and pull requests
- maintain benchmarks and regression gates
- cut releases and publish release notes
- document known limitations and adoption evidence honestly

## Becoming a Core Maintainer

Core maintainer status can be granted after sustained, reviewable contributions across:

- workflow correctness
- validator and benchmark quality
- documentation and examples
- security and safety review
- community support

The primary maintainer makes final maintainer-status decisions until a larger maintainer group exists.
