# CNIPA Filing Readiness

Use this reference for China filing operations, XML readiness, receipts, fees, and docketing.

## CNIPA Readiness Checklist

Confirm:

- Filing type and case metadata.
- Applicant, inventor, contact, agent, and address fields.
- Final claims, specification, abstract, drawings, and request metadata.
- Priority claim, divisional, same-day invention/utility model, or PCT data if relevant.
- Secrecy review status for invention/utility model matters where needed.
- Official XML standard/tool/schema version and validation output.
- Final package hash and reviewed version hash.
- Fee reduction and fee payer information.
- Authorized filing account and signature authority.
- Receipt capture plan.

## XML Package Validation

Validate:

- Schema conformity.
- Required fields.
- Attachment list.
- Character encoding.
- Formula/table/image conversion.
- Drawing reference consistency.
- Claim numbering and dependencies.
- Abstract and title presence.
- Sequence listing branch if applicable.

If schema or official tool validation fails, stop filing and output a deficiency report.

## Authorized Filing Boundary

Proceed with automated submission only if:

- Legal gates pass.
- Official channel permits the chosen automation path.
- Account and signature authority are documented.
- The automation does not bypass captcha, electronic signature, multi-factor, or official access control.
- The system can capture official receipt or official status evidence.

If a human-only step appears, stop and produce a handoff:

- Exact screen/action.
- Package hash.
- Account role required.
- Deadline.
- Risk if delayed.

## Receipt Handling

After filing action, capture:

- Official receipt.
- Application number if issued.
- Submission timestamp.
- Official file list.
- Fee status.
- Next deadlines.

Do not mark a case as accepted without official evidence.

## Docket Entries

Create docket entries for:

- Filing date.
- Priority deadline.
- Fee due date.
- Formality response deadline.
- Substantive examination request deadline if applicable.
- Office action response deadlines.
- PCT/national phase deadlines where relevant.
- Annual fee or maintenance reminders.
