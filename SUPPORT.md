# Support

Use GitHub issues for public support.

## Good Support Requests

Please include:

- what command you ran
- your operating system
- Python version
- relevant input folder shape
- the validator or script output
- whether the issue involves local generation, validation, handoff, or publishing

## Do Not Post Publicly

Do not include:

- real applicant secrets
- official account credentials
- private inventor data
- confidential invention materials
- payment information
- real filing receipts unless they are safe to publish

Use the private reporting path described in `SECURITY.md` for sensitive issues.
