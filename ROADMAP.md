# Roadmap

This roadmap is evidence-driven. Items may change as users test real workflows and report needs.

## Current State

The local skill loop is complete through read-only pre-submission handoff:

- intake
- reference-patent delta
- draft generation
- evidence provenance
- abnormal filing risk
- AI legal/compliance gate
- application materials
- quality review
- handoff package
- inbox handoff index
- completion audit
- regression gate

## Near-Term

- publish a public GitHub repository
- add small, public example inboxes that are safe to inspect
- improve onboarding docs for first-time users
- add issue templates for adopter reports and workflow questions
- document integration boundaries for downstream filing adapters

## Mid-Term

- add a minimal CLI wrapper with stable command names
- add a packaging strategy for installation
- add more jurisdiction-specific preflight references
- add richer example reports for non-sensitive sample cases
- add GitHub release automation

## Long-Term

- build a production intake service around the skill
- add a dashboard for case status and quality review
- design official filing adapters with strict authorization boundaries
- create an ecosystem of plugins for patent search, docketing, and portfolio analytics

## Not In Scope By Default

- bypassing official filing controls
- real official submission without lawful authorization
- legal advice claims
- fake attorney or patent-agent review claims
- fabricated usage, stars, adopters, or downstream dependencies
