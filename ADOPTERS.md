# Adopters

This file tracks public adoption evidence for Patent Capital OS.

## Public Adopters

No public adopters are listed yet.

That is intentional: this repository should not claim ecosystem importance until there is public evidence. If you use Patent Capital OS in a public workflow, benchmark, evaluation, integration, or internal pilot that can be mentioned publicly, please open an adopter issue.

## How to Add an Adoption Entry

Open an issue using the "Adopter report" template and include:

- organization or project name
- public URL, if available
- use case
- version or commit used
- whether the use is evaluation, pilot, production, research, or education
- any public quote we may include

Maintainers will verify the entry before adding it here.

## Adoption Evidence Types

Good public evidence includes:

- public downstream repository
- public issue or discussion
- public integration guide
- public benchmark or evaluation
- public article or citation
- public release note that mentions Patent Capital OS
